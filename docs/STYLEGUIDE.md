# Styleguide

`styleguide.html` is the UIkit-oriented visual reference for the clickdummy.

Each component section follows:

1. description
2. Preview
3. Markup
4. useful variants
5. link to upstream UIkit documentation.

Preview and Markup use the same example source:

```html
<!-- @include partials/styleguide/buttons.html -->
<!-- @include-code partials/styleguide/buttons.html -->
```

Examples under `partials/styleguide/` are prototype-only and are not promoted
blindly into productive Kalkurama.

The Styleguide should document UIkit components Kalkurama actually uses plus
true Kalkurama-specific compositions such as project context and timer/workflow
surfaces.
